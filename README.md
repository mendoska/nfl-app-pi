# Sport App 

![](https://github.com/mendoska/nfl-app-pi/blob/main/nfl-app.gif) 
A real-time sports scoring application that displays live game data from the ESPN API.

**Live Demo:** https://sports-scoring-app-ksa1.onrender.com/

Please note: Website a cold start of about 1-2 minutes when inactive for 15 minutes, after which will load normally on all platforms. 



## Tech Stack
- **Backend:** Flask (Python)
- **Frontend:** HTML, CSS, JavaScript
- **API:** ESPN API
- **Deployment:** Render

## Features
- Real-time scores for NFL, NBA, and NHL
- Dark mode toggle
- Clean, responsive interface
- Upcoming game schedules
